# JARVIS privacy policy

JARVIS is a personal home assistant that one person (its author) runs on their
own computers. It is not offered to anyone else.

**What it accesses.** With the owner's consent through Google's sign-in,
JARVIS reads the owner's Google Calendar (read-only) and Gmail, to tell the owner about
upcoming events and to sort their own inbox.

**Where data goes.** Calendar and email data stays on the owner's own home
server. Text JARVIS needs in order to answer is sent to Anthropic's API to
generate a reply. Nothing is sold, shared with advertisers, or given to anyone
else.

**Removing access.** Access can be revoked at any time at
https://myaccount.google.com/permissions. Deleting the token files on the home
server removes JARVIS's stored sign-in.

Google user data is used in line with the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including its Limited Use requirements.
